# Koshkastom

A Kotlin library for Minestom containing useful DSLs and hundreds of extensions.

## Installation

::: code-group

```kts [Gradle (Kotlin)]
repositories {
    maven("https://maven.skylite.gg/releases")
}

dependencies {
    implementation("gg.skylite:koshkastom:2026.08.29-26.2")
}
```

```groovy [Gradle (Groovy)]
repositories {
    maven {
        url 'https://maven.skylite.gg/releases'
    }
}

dependencies {
    implementation 'gg.skylite:koshkastom:2026.08.29-26.2'
}
```

```xml [Maven]
<repositories>
    <repository>
        <id>skylite</id>
        <url>https://maven.skylite.gg/releases</url>
    </repository>
</repositories>

<dependencies>
    <dependency>
        <groupId>gg.skylite</groupId>
        <artifactId>koshkastom</artifactId>
        <version>2026.08.29-26.2</version>
    </dependency>
</dependencies>
```

:::
