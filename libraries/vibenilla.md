# Vibenilla

An experiment to slowly implement vanilla features in Minestom

## pvp

::: code-group

```kts [Gradle (Kotlin)]
repositories {
    maven("https://maven.skylite.gg")
}

dependencies {
    implementation("rocks.minestom:pvp:2026.08.28-26.2")
}
```

```groovy [Gradle (Groovy)]
repositories {
    maven {
        url 'https://maven.skylite.gg'
    }
}

dependencies {
    implementation 'rocks.minestom:pvp:2026.08.28-26.2'
}
```

```xml [Maven]
<repositories>
    <repository>
        <id>skylite</id>
        <url>https://maven.skylite.gg</url>
    </repository>
</repositories>

<dependencies>
    <dependency>
        <groupId>rocks.minestom</groupId>
        <artifactId>pvp</artifactId>
        <version>2026.08.28-26.2</version>
    </dependency>
</dependencies>
```

:::
